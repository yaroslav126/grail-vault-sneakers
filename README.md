# The Sneaker Vault 👟🏛️

> The premier destination for authenticated luxury footwear, archival grails, and verified consignment.

A refined digital salon and archival catalog designed with a deep obsidian canvas and rich dark contrast emerald palette. Every showcase piece features laboratory physical verification, multi-currency valuations, and seamless acquisition workflows.

---

## 🌟 Key Features

- **Archival Haute Collection**: Curated selection of premier atelier footwear (Dior, Travis Scott, Off-White, Louis Vuitton, Rick Owens, Balenciaga, and rare Jordan grails).
- **12-Point Laboratory Standard**: In-depth physical verification standard modal covering UV luminescence, durometer elasticity, scale micro-calibration, and RFID serial audits.
- **Dynamic Multi-Currency Engine**: Instant live switching between **USD ($)**, **EUR (€)**, and **GBP (£)** across all shoes, spotlight showcases, search filters, and checkout ledgers.
- **Verified Consignment & Buyout**: Consignor workflow offering listing preferences and immediate buyout calculations.
- **Interactive Shopping Bag & Wishlist**: Real-time sliding drawer carts, promo code discounts, and favorite saves.
- **Responsive & Modern Window Animations**: Spring-based Framer Motion window transitions, glassmorphism surfaces, and emerald ambient glows.
- **Client Inquiries & Work Requests**: Exclusive direct contact routed to Telegram bot [`@Slava_Dev_bot`](https://t.me/Slava_Dev_bot) with a guaranteed 24-hour response turnaround.
- **Anti-Copy & Anti-AI Protection**: Comprehensive selection, drag, and print shields paired with W3C Text & Data Mining (TDM) reservations and canary watermarks.

## 🚀 Getting Started

### Prerequisites

Ensure [Node.js](https://nodejs.org/) (v18+) and `npm` are installed on your machine.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/yaroslav126/grail-vault-sneakers.git
   cd grail-vault-sneakers
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Launch the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```

5. Preview the production build:
   ```bash
   npm run preview
   ```
